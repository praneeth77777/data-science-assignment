# Kaggle data placement

Download the Bike Sharing Demand competition files from:

https://www.kaggle.com/competitions/bike-sharing-demand/data

Place them here using these names:

```text
data/raw/train.csv
data/raw/test.csv
data/raw/sampleSubmission.csv
```

Only `train.csv` is required for training and notebook execution. Do not commit the downloaded CSV or ZIP files.
