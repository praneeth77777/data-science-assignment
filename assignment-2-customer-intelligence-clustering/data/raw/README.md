# Raw Online Retail data

The raw workbook is deliberately excluded from Git.

Source: UCI Machine Learning Repository, Online Retail, DOI 10.24432/C5BW33, CC BY 4.0.

Download automatically from this project directory:

```bash
python scripts/download_data.py
```

Expected path:

```text
data/raw/Online Retail.xlsx
```

Official dataset page: https://archive.ics.uci.edu/dataset/352/online+retail
